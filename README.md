# PROJETO-QRCODE
Projeto desenvolvido no bootcamp da DIO para gerar QR Codes de forma simples com Node.js. A aplicação cria códigos para links, textos e dados rápidos, facilitando testes e uso no dia a dia. O foco é praticar lógica, modularização e organização de código, transformando um caso real em aprendizado prático e funcional para portfólio e estudos online!!
